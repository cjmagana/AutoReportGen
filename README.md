# AutoReportGen Automation Pipeline

A Python-based workflow designed to automate data cleaning, analysis, and reporting for business intelligence.

## Features
-  **Interactive Notebook:** User can specify input CSV via notebook cell.
-  **ETL Pipeline:** Automates extraction, transformation (date cleaning/missing value handling), and loading of key metrics.
-  **Automated Visualization:** Generates executive-ready charts (PNG) without manual intervention.
-  **Scalability:** Designed to handle datasets > 100k rows efficiently using Pandas vectorization.
